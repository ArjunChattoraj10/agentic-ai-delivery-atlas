# Agentic AI Delivery Atlas

An interactive guide to planning, building, evaluating, releasing, operating, and retiring an Agentic AI solution.

**Live guide:** https://arjunchattoraj10.github.io/agentic-ai-delivery-atlas/

## Highlights

- Nine lifecycle stages and five continuous workstreams with dedicated deep dives
- Detailed guidance for 45 delivery activities
- Plain-language explanations, implementation steps, evidence, and common considerations
- Dedicated knowledge-base and Retrieval-Augmented Generation (RAG) guidance
- Searchable Agentic AI glossary with 110 definitions across eight disciplines
- Search, filtering, responsive layouts, and dark mode

## Run locally

Serve the repository with any static web server, then open `index.html`. No build step or external dependencies are required.
